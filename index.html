TTUI

A terminal UI framework built from first principles. 02 — Verify it
github.com/tatemeyer/parallax

Parallax

A platform for watching and steering agent-driven work across projects. Its first component, Plumb, captures a running terminal app under a PTY and hands the result to four blinded critic agents — each sees only the image and a run manifest, never the source or the diff. Their findings merge into a single GO / NO-GO / HOLD, and a HOLD blocks just like a NO-GO, naming the lens that could not report. The model that wrote the code doesn’t get to grade it.

github.com/tatemeyer/Model-Experiments

Model-Experiments

ML research pointed at the loop itself: physics-informed ML for electromagnetics — a verified PINN solving the 1D perfect-electric-conductor cavity wave equation against a closed-form solution — and JEPA work on what actually prevents representation collapse at toy scale. Built with Bitter Lesson Engineering: intent is filed as a GitHub Issue describing the desired end state and how to verify it, an agent implements against that intent, and CI decides when it’s done.

How I work

Spec-first

No implementation without an approved design doc and a plan. Every feature goes brainstorm → design → plan → build, and the docs stay in the repo as the record.

Blinded verification

The author doesn’t grade the work. Critics see the artifact and nothing else — not the source, not the diff, not who wrote it.

CI is truth

“Done” is a green pipeline, not an opinion. Intent states how a change can be verified before anyone writes the code that satisfies it.

Explicit autonomy

Every unit of work declares how much human review it needs. Some changes merge themselves on green CI; others never do, and the label says which.
